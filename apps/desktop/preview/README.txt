Desktop Buddies 0.1.0

To run it
1. If an earlier version is still running, quit it from its tray icon.
2. Unzip this whole folder somewhere you'll keep it, like Documents. Keep
   the "app" folder next to desktop-buddies.exe.
3. Double-click desktop-buddies.exe. The Manager opens. No buddies are
   included: use Import for a .buddy file or a Shimeji folder, or New buddy
   to make one in the Maker.

To open the Manager
Right-click the tray icon, near the clock, and pick Open Manager. You may need
the little arrow to find the icon.

To make a buddy
In the Manager, New buddy starts one. To change a buddy, use its ••• button and
pick Edit.

If Windows stops it
This build isn't signed, so Windows may warn you.
- "Windows protected your PC": click More info, then Run anyway.
- "Smart App Control blocked this" or similar: there's no way past that one.
  Please don't turn Smart App Control off for this. You can build the exe
  yourself from the source instead.

To remove it, turn Start with Windows off first if you turned it on, then quit
from the tray and delete the folder. Your buddies and settings are in
%APPDATA%\dev.exvanitas.desktop-buddies, which you can delete too.
